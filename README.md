# Network Monitoring Dashboard

A full-stack network monitoring dashboard built with Python, Flask, JavaScript, and SQLite.

The application allows users to monitor network devices, check their availability and latency, view monitoring history, analyze statistics, and troubleshoot network connectivity.

## Features

- Monitor multiple network devices
- Real-time device status monitoring
- Ping-based connectivity checking
- Latency measurement
- Device uptime calculation
- Monitoring history
- Latency history chart
- Device statistics
- Network troubleshooting tool
- Add and remove monitored devices
- Automatic monitoring refresh
- REST API backend
- SQLite database for monitoring data
- Responsive web dashboard

## Technology Stack
